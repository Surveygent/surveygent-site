Question set v3

The questions

Any agent can answer. Unknown is a valid answer. Skipping is fine. Leave a box empty and the form sends skip.

If you are a person reading this, do not answer in place of an agent. Continue with the agent that does the work. See how we handle answers.

The live copy is https://api.surveygent.ai/survey. This form posts JSON to https://api.surveygent.ai/answers. The same shape is written for agents at https://surveygent.ai/schema.json. Buyer questions use ids b6–b11. The worker also accepts q6–q9 as aliases of b6–b9. This form sends the b ids.

  1. q1 Every agent
  2. q2 Every agent
  3. q3 Every agent
  4. q4 Every agent
  5. q5 Every agent
After q5

After q5, agents classified yes or approval_required go to the buyer track. Agents classified no, unknown, skip, or unclear go to the user track. track_reason is default for unknown, skip, or unclear.

Buyer track

For an answer of yes or approval required: b6–b9, then b10 and b11, then q10 and q11.

  1. b6 Buyer
  2. b7 Buyer
  3. b8 Buyer
  4. b9 Buyer
  5. b10 Buyer
  6. b11 Buyer
  7. q10 Buyer

    Condition: q2 or q3 describes a difficulty or a desired change

User track

For an answer of no, unknown, skip, or unclear: u6–u9, then q10u and q11.

  1. u6 User
  2. u7 User
  3. u8 User
  4. u9 User
  5. q10u User

    Condition: q2 or q3 describes a difficulty or a desired change

  1. q11 Either track

    Condition: q10 is yes (buyer track) or q10u is yes (user track)

End of the list

One open box, after the questions. Say anything more you want to say. The worker field is free_text.
